# Potential Skill Pages

Pages for the **Potential Skills** list, so you can buy skills past the first 36.

## What it changes

- The game shows only the first 36 skills a character can buy, and cuts the rest. With this mod the
  list holds up to 144, 36 to a page, with **Previous Page** and **Next Page** buttons under it.
- The list opens on page 1. An arrow that would leave the list is greyed out and plays the game's
  deny sound.
- The arrow keys reach the two buttons: Down from the last skill of a column. Under the mouse or the
  keys, a button tells you the page, such as "Page 2 of 3".
- Buying a skill keeps you on the same page. Closing and opening the menu goes back to page 1.

For example, Wichita's **Spellblade Knowledge** (from the Spellblade Knowledge mod) is on page 2
when page 1 is full.

## Keys and settings

None.

## Saves

Nothing.

## Works with

Mods that add shop skills, such as Spellblade Knowledge, Kaoru Quincy QoL and Onoha QoL.

## Install

Needs [RQ MOD](https://github.com/RQ-Modding/RQ-Mod) with loader **2.17.0** or newer. Extract the
release zip into the game's `mods` folder, so that you have `mods/potential-skill-pages/mod.json`.
